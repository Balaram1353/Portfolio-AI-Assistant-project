# Portfolio AI Assistant

An interactive AI-powered portfolio chatbot that answers questions about my professional background, data science experience, technical skills, and projects. Built with a JavaScript frontend, FastAPI backend, and NVIDIA Nemotron through LangChain.

## Features

- **Conversational portfolio assistant** — Ask questions about my skills, experience, education, and projects.
- **LLM-powered responses** — Uses NVIDIA Nemotron via LangChain.
- **Portfolio-aware retrieval** — Retrieves relevant information from structured portfolio data to ground responses in my profile.
- **REST API** — FastAPI endpoint for chat requests and a health-check route.
- **Input validation** — Rejects missing, empty, and whitespace-only questions.
- **Error handling** — Returns appropriate API errors when the model request fails.
- **Automated tests** — Includes API and chat endpoint tests.
- **Secret management** — Loads the NVIDIA API key from environment variables rather than hardcoding it.

## Prerequisites

- Python 3.14 or another Python version compatible with the dependencies
- Git
- An NVIDIA API key with access to the configured model
- A modern web browser

Get your API key from the [NVIDIA Developer Portal](https://build.nvidia.com/).

## Installation and Setup

### 1. Clone the repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_URL>
cd "portfolio project"
```

Replace the placeholder URL with your GitHub repository URL.

### 2. Create and activate a virtual environment

On Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
python -m pip install -r requirements-dev.txt
```

### 4. Configure environment variables

Copy the example environment file:

```powershell
Copy-Item .env.example .env
```

Open `.env` and replace the placeholder with your NVIDIA API key:

```dotenv
NVIDIA_API_KEY=your_actual_nvidia_api_key
```

**Security:** Never commit your real `.env` file or expose your API key in frontend JavaScript, public repositories, screenshots, or logs.

### 5. Start the backend

From the project root, run:

```powershell
python -m uvicorn backend.main:app --reload
```

The API will be available at:

- API base URL: `http://127.0.0.1:8000`
- Interactive API documentation: `http://127.0.0.1:8000/docs`
- Health check: `http://127.0.0.1:8000/`

### 6. Start the frontend

Open a second PowerShell terminal from the project root:

```powershell
cd frontend
python -m http.server 5500
```

Open [http://127.0.0.1:5500](http://127.0.0.1:5500) in your browser.

Keep both terminals running while using the application locally.

## API Usage

### Health Check

**Request**

```http
GET /
```

**Example response**

```json
{
  "message": "Portfolio AI Chatbot API is running!"
}
```

### Chat Endpoint

**Request**

```http
POST /chat
Content-Type: application/json
```

**Example request body**

```json
{
  "question": "Who is Balaram? Give me a short introduction."
}
```

**Example response structure**

```json
{
  "question": "Who is Balaram? Give me a short introduction.",
  "answer": "An AI-generated response based on the available portfolio information."
}
```

The answer shown above is illustrative; actual output is generated by the configured model.

Interactive API documentation is available at `http://127.0.0.1:8000/docs` while the backend is running.

## Running Tests

Run the automated test suite from the project root:

```powershell
python -m pytest tests -v
```

The current development test suite contains **14 passing tests**, covering:

- Health endpoint behavior
- Missing and invalid questions
- Empty and whitespace-only input
- Successful chat responses
- Simulated model failures
- API error handling

## Configuration and Security

- Keep secrets in `.env`, which is excluded by `.gitignore`.
- Use `.env.example` to document the required environment variables without exposing credentials.
- Do not expose the NVIDIA API key in browser-side code.
- The local CORS configuration should be restricted to the deployed frontend origin before production deployment.
- Configure production environment variables using your hosting provider's secret-management facilities.

## Current Limitations

- Responses depend on the availability and access limits of the configured NVIDIA model.
- Portfolio answers are limited by the accuracy and completeness of the stored portfolio information.
- The current setup is intended for local development; public deployment requires production hosting and security configuration.
